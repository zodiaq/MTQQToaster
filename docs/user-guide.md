# 操作マニュアル

[ドキュメント一覧](README.md) · [現行仕様](../SPECIFICATION.md)

## 起動と初期設定

[ビルド](development/build.md)した`MTQQToaster.exe`を起動します。通常は設定ウィンドウを開かず通知領域に常駐します。アイコンが見えないときは、隠れたアイコンも確認してください。

トレイアイコンは、Windowsの「個人用設定 → 色」で指定するWindowsモードに合わせ、ダークでは白、ライトでは黒へ自動で切り替わります。実行中の変更にも対応します。カスタムモードではアプリモードではなくWindowsモードに従います。

トレイを右クリックして「設定...」を開き、MQTT接続先、必要な認証情報、購読トピックを入力して保存します。接続先は`mqtt://host:1883`または`mqtts://host:8883`形式です。ユーザー名・パスワードは専用欄へ入力します。

トピックを追加するには一覧末尾の「<新規>」を選び、トピックと必要な画像を入力して「更新」を押します。既存の項目は選択して更新・削除できます。一覧に収まらない項目はホイールまたは上下キーで移動します。`+`や`#`も使えます。送信側と一致するよう設定し、[メッセージ形式](reference/payload.md)に従って送信してください。

初回はEXE横の`config.json`、なければ`config.sample.json`を取り込みます。サンプルの接続先は利用環境に合わせて変更してください。両方ない場合は内部既定値を使い、設定保存時にファイルを作成します。

## 画像と設定画面

トピックごとにPNG、JPEG、GIFの既定画像を選べます。画像は設定フォルダーへコピーされ、解除して保存すると未使用の管理画像は削除されます。メッセージ側の画像指定が優先されます。

設定画面は固定サイズで、リサイズ・最小化・最大化は行いません。設定項目と保存・キャンセルは画面内に収まり、画面全体のスクロールはありません。小さな作業領域では全体を縮小して表示します。位置は閉じると保存されます。Shiftを押しながらトレイの「設定...」を選ぶと配置を初期化できます。旧バージョンで保存したサイズ・最大化状態は使用しません。

画像を選択すると「更新」「削除」の右側にサムネイルが表示されます。画像パスを直接入力した場合は、画像欄からフォーカスを移すと更新されます。画像の解除・新規項目の選択でプレビューも消えます。

設定画面は接続・購読・ログを同じ画面内のカードにまとめています。設定画面を閉じても常駐し、UIホストを非表示で保持します。アプリを終了するにはトレイの「終了」を選びます。

設定画面・トレイメニュー・入力エラーはWindowsの表示言語に合わせ、日本語では日本語、それ以外では英語で表示します。OSのファイル選択画面やシステムメニューの言語はWindows側に従います。言語を変えた場合はアプリを再起動してください。

Windows 11ではタイトルバーと設定画面の背景を揃えた一体型ヘッダーを使用します。上部をドラッグして移動できます。タイトルバーのボタンはOS標準の「閉じる」のみです。Windows 10とハイコントラスト時は標準のウィンドウ枠を使用します。

右クリックメニューはアイコン付きで、Windowsモードに合わせて明暗が切り替わります。Windows 11では角丸になります。上下キー・Tabで移動し、Enterで実行、Escまたは別ウィンドウへの切り替えで閉じます。ハイコントラスト時やXAMLメニューを初期化できない場合は標準メニューを使用します。

## 自動起動

トレイのスタートアップ項目で登録・解除します。現在のユーザーのWindowsログオン時に起動します。EXEを移動する場合は解除し、移動後に登録し直してください。

MSIX版ではトレイの「Windowsのスタートアップ設定...」からWindows設定を開いて切り替えます。初期状態は無効です。導入とEXE版からの移行は[MSIX手順](development/msix.md)を参照してください。

## 保存場所とログ

通常は`%LOCALAPPDATA%\MTQQToaster`に保存します。

- `config.json`：接続先、認証情報、購読、ログ設定。
- `ui-state.json`：画面配置。
- `topic-image-*`：設定画面から登録した画像。
- `ToastAssets/`：メッセージから相対指定する画像の配置先。
- `Logs/app.log`：動作ログ。サイズと保持数に従ってローテーションします。

JSONの直接編集は不要です。バックアップや共有時は`config.json`に認証情報が含まれることに注意してください。詳細は[設定仕様](reference/configuration.md)を参照してください。

## 困ったとき

- 接続できない：URL・ポート・認証情報とログを確認します。TLSではWindowsが信頼するCAと、証明書のSANに一致する接続先名が必要です。証明書検証を無効にする設定はありません。
- 通知が出ない：接続・購読ログ、送信トピック、Windowsの通知設定を確認します。タイトルには[現在の制約](reference/payload.md)があります。
- 画像が出ない：HTTP/HTTPS画像は非対応です。[画像の指定方法](reference/payload.md)を確認します。
- 画面が見えない：Shiftを押しながら「設定...」を選びます。
- ログのサイズ・保持数を変更した：反映には再起動が必要です。ログレベルは実行中に反映されます。
