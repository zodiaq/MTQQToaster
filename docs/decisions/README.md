## 記録の追加

`NNNN-短い主題.md`で作成し、この索引へ追加します。日付と状態（検討中／採用／却下／廃止）、背景、選択肢、判断と理由、影響、未解決事項、関連する実装・仕様を記載します。

調査していない比較や存在しない合意を作らず、未決定なら明記します。採用後は現行資料へ反映し、記録には経緯を残します。後続の判断で置き換える場合は相互リンクを付けます。
