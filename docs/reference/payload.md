# MQTTメッセージ リファレンス

[ドキュメント一覧](../README.md) · [現行仕様](../../SPECIFICATION.md)

購読済みトピックへUTF-8で送信します。推奨例：

```json
{
  "message": "玄関のセンサーが反応しました",
  "image": "snapshot.jpg"
}
```

## 解析規則

- `message`：文字列なら本文になります。省略または文字列以外なら、受信ペイロード全体が本文になります。
- `title`：文字列なら内部のタイトル値を置き換えます。省略時は`MQTT Toaster`です。
- `image`：文字列なら画像として使用します。文字列の`image`がなければ互換名の`image_url`を参照します。

JSONとして解析できない文字列はそのまま本文にします。`洗濯が終わりました`だけでも送信できます。必須キー不足で拒否する処理ではありません。

**現行実装の制約：** `title`は本文の見出しとして表示されず、`CreateToastNotifier`の通知元識別子へ渡されます。本文のテキストノードには`message`だけを設定します。任意の`title`を指定した場合の表示を保証するものではありません。

## 画像

ペイロードの画像が空でなければそれを使い、空なら一致する購読トピックの既定画像を使います。HTTP/HTTPS画像は非対応です。無効な画像指定からトピック画像へ戻す処理ではありません。

相対パスは次の順で探索します。

1. 設定フォルダー直下。
2. 設定フォルダーの`ToastAssets/`。
3. EXEのディレクトリ（互換動作）。

ローカル／UNCパス、`file:` URIを処理します。`ms-appx:///`と`ms-appdata:///`もコード上は受け付けますが、解決可否は実行環境に依存し、通常の非パッケージ配布での利用を保証しません。

画像の埋め込みやHTTPダウンロード機能はありません。ファイルは受信側でアクセスできる場所に配置してください。
