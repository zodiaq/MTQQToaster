# 2026-11-07：一体型ヘッダーと日英表示

[検証記録一覧](README.md)

## 対象

OS内蔵XAML設定画面の一体型ヘッダーと日英表示を追加した作業ツリー。Windows 11ビルド26300、Windows SDK 10.0.26100.0、MSVC 19.51。C++、静的CRT、OS内蔵XAMLを維持し、OS標準のDwmapiのみリンクに追加した。

## 実装

- Windows 11ではDWMのキャプション色対応を確認して44 DIPのヘッダーを確保し、XAML背景に色を合わせる。標準のキャプションボタン、移動、ダブルクリック、サイズ変更を利用する。
- Windows 10やハイコントラストでは標準枠へフォールバックする。
- 設定画面、入力エラー、トレイメニュー、MSIXのスタートアップ項目を日英の共通辞書へ移した。日本語以外の表示言語は英語にフォールバックする。OS自身のダイアログとシステムメニューはOSの表示言語に従う。
- 日英のプレビュー／スモーク用引数は試験プロセス内だけで言語を固定する。

## 結果

- 通常のReleaseビルド成功、`ctest --preset x64-release`は29件成功。
- 独立した`out/build/xaml-validation`のDebugビルド成功、同ディレクトリの`ctest -C Debug`は29件成功。
- Debug／Releaseとも`--ui-smoke-test-ja`と`--ui-smoke-test-en`が終了コード0。位置・サイズ復元、ログ列の整列、保存・キャンセル、トピック編集、設定監視、初期化中の終了を確認。
- 全翻訳項目の存在、日本語以外の英語フォールバック、MQTT検証エラーの言語、通常／MSIXのトレイメニュー文字列をGoogleTestで確認。実ブローカーやトレイ登録は試験に使わない。
- 英語プレビューの画面で一体型ヘッダーと標準ウィンドウボタン、英語ラベル・説明文を確認。最大化ボタン、最大化後のヘッダーダブルクリックによる復元、閉じるボタンの座標クリックを確認。ドラッグ操作も実施したが移動量は計測していない。

## 検出した問題

- DWM拡張領域が1pxの試作ではキャプションボタンが表示されなかった。ヘッダー高さ全体へ拡張して表示を確認。
- Debugの初回レイアウト判定で幅0・配置座標0の状態を検出。XAMLが非同期に最初のレイアウトを行うため、最大5秒の完了待ちを追加した。既存の配置・整列条件は維持し、日英の再試験が成功。
- app_logic.cppの既存の型変換・未使用変数警告、およびfmtの到達不能コード警告は残る。

## 未確認

Windows 10フォールバック、ハイコントラスト、異なるDPI間の移動、Snap Layoutsのホバー表示、実トレイメニューの目視、署名済みMSIXのインストールは未確認。言語の単体テストでは通常／MSIX双方のメニュー文字列を検証したが、MSIX配布検証の代わりにはならない。
